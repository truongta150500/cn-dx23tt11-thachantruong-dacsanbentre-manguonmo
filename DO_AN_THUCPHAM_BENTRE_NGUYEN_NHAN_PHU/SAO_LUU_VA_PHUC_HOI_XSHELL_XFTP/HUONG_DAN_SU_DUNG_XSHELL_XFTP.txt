HƯỚNG DẪN THAO TÁC SAO LƯU VÀ PHỤC HỒI DỮ LIỆU QUA XSHELL VÀ XFTP
========================================================================================

PHẦN 1: KẾT NỐI VÀ SAO LƯU QUA DÒNG LỆNH XSHELL 7
----------------------------------------------------------------------------------------
1. Mở phần mềm Xshell 7 trên máy Windows.
2. Tạo phiên kết nối (New Session):
   - Host: 127.0.0.1
   - Port: 2222
   - Protocol: SSH
3. Nhập tài khoản:
   - Username: bentre
   - Password: Admin@2026
4. Chạy lệnh sao lưu toàn diện:
   $ bash /home/bentre/backup.sh

   Hệ thống sẽ thực thi tự động:
   - Xuất file CSDL: /home/bentre/backups/db_thucpham_[NGAY_GIO].sql
   - Nén mã nguồn:   /home/bentre/backups/files_thucpham_[NGAY_GIO].tar.gz


PHẦN 2: LƯU TRỮ NGOẠI VI AN TOÀN QUA GIAO DIỆN ĐỒ HỌA XFTP 7
----------------------------------------------------------------------------------------
1. Mở phần mềm Xftp 7 trên máy Windows.
2. Tạo kết nối SFTP:
   - Host: 127.0.0.1
   - Port: 2222
   - Username: bentre
   - Password: Admin@2026
3. Thao tác tải bản sao lưu về máy (Download):
   - Cửa sổ bên trái (Local): Chọn thư mục lưu trữ trên máy Windows.
   - Cửa sổ bên phải (Remote): Vào thư mục /home/bentre/backups/.
   - Kéo thả 2 file (.sql và .tar.gz) từ cửa sổ bên phải sang bên trái.


PHẦN 3: PHỤC HỒI HỆ THỐNG KHI GẶP SỰ CỐ (DISASTER RECOVERY)
----------------------------------------------------------------------------------------
1. Đưa 2 file sao lưu lên máy chủ qua Xftp:
   - Kéo file .sql và .tar.gz từ máy tính sang thư mục /home/bentre/backups/ trên máy chủ.
2. Mở Xshell và chạy lệnh phục hồi tự động:
   $ bash /home/bentre/restore.sh

   Hệ thống sẽ tự động thực hiện trong 15 giây:
   - Xóa bỏ CSDL lỗi, tái tạo CSDL sạch và nạp lại toàn bộ bảng dữ liệu.
   - Giải nén mã nguồn website sạch vào thư mục /var/www/html/thucpham.
   - Thiết lập quyền sở hữu cho máy chủ web: chown -R www-data:www-data.
   - Phân quyền bảo mật 755 (thư mục) và 644 (tệp tin).
   - Khởi động lại dịch vụ Apache và kiểm tra HTTP 200 OK.
3. Mở trình duyệt kiểm tra:
   - Truy cập http://localhost:8080/thucpham/ để xác nhận website đã phục hồi nguyên vẹn.
