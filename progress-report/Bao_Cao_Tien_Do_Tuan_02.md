## 1. NỘI DUNG CÔNG VIỆC TRONG TUẦN
* **Trọng tâm:** Nhiệm vụ 1: Cài đặt máy chủ ảo mã nguồn mở LAMP Stack

## 2. KẾT QUẢ ĐẠT ĐƯỢC
Cài đặt Linux Ubuntu Server 22.04 LTS trên Oracle VirtualBox. Cấu hình NAT Port Forwarding (8080 cho HTTP, 2222 cho SSH/SFTP). Cài đặt và tối ưu Apache 2.4, MySQL Server 8.0, PHP 8.1 và các mô-đun cần thiết. Viết kịch bản `setup_lamp.sh` tự động hóa.
